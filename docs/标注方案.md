## 流程总览

```
你拍照片（任意手机，尽量 3000px 宽以上）
   ↓
① 预标注（我来跑）：部署同口径自动打框（conf 0.45 + 双模型 + 去重）
```

## ① 预标注（我来跑，你只需提供照片）

把照片放进一个目录（或直接用手机拍完传到电脑），告诉我路径。我会跑：

```sh
training/venv/bin/python training/user/preannotate_for_labeling.py \
    --photos <照片目录> --out training/datasets/<数据集名> --previews
```

输出三样东西：
- `images/`——你的照片切成 1280 切片（与训练/识别分布一致）
- `labels/`——YOLO 格式预标注
- `previews/`——全图标注预览（你可以先看预览决定哪些照片值得细标）

## ② 你修正（labelImg，每次 10–30 分钟）

安装（一次性）：

```sh
training/venv/bin/pip install labelImg
```

打开（命令我会在预标注完成后给你现成的）：

```sh
training/venv/bin/labelImg <images目录> <classes.txt> <labels目录>
```

界面操作要点：
- 左侧工具栏选 **Create RectBox** 框牌，框完弹类别选择
- 选中已有框（点击）可 **拖动边角收紧**、**Del 删除**
- 左侧勾选 **Use predefined labels**（不再每次弹类别选择）
- **Ctrl+S 保存**，右下角箭头下一张
- 快捷键：W 新建框 / D 下一张 / Del 删除框

**修正重点（按你反馈的三类问题）**：
1. **重复框**：同一张牌两个框 → 删掉差的那个
2. **过大框**：框明显大于牌面 → 收紧到贴边
3. **漏框**：没有框的牌 → 补上（这是对识别率影响最大的）

**标注规则**：
- 每张**可见的牌**一个框，贴着牌的边缘画（不含桌面）
- 被遮挡的牌：**可见部分 ≥ 一半就框**（框可见部分对应的完整牌位）；只露一小角的跳过
- **牌背只标蓝/绿背**；黑色/红色等其他颜色背一律不标（它们是"非牌背"负样本）
- 牌堆叠场景：每张**可见**的牌都框（这个场景模型最弱，你的标注直接补盲区）
- 类别表：wan1–wan9（一万~九万）/ tong1–tong9（筒）/ tiao1–tiao9（条）/ back（蓝绿背）

## ④ 数量建议

先标 **20–30 张**（重点：堆叠、暗光、你实际使用时的真实摆法），训完看效果再加。
每张全铺照片约 3–8 分钟（预标注能帮你省 80% 工作量）。

- 自动标注的膨胀问题（重复/过大）源于低阈值预标（偏召回），新脚本已改为部署同口径 0.45 + 去重，预标质量比 8/31 批次好得多——你修正的量会小很多
- 黑背误报的根治 = 训练数据里剔除全部非蓝绿背标签（已完成 18,543 处清洗）+ App 端色彩门控兜底（已上线）
- 近乎 100% 的路径：人工精标（本方案）→ QAT 训练（天然耐 int8 量化）→ 回归集验证闭环
